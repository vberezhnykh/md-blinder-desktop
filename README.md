# MD Blinder Desktop

Настольная версия MD Blinder для Windows на Python и PySide6. Делает то же, что браузерная: конвертирует DOCX и PDF (включая сканы) в Markdown, находит персональные данные регулярными правилами и моделью GLiNER, дает проверить кандидатов и выгрузить обезличенный текст. Документы обрабатываются на компьютере и никуда не отправляются.

## Что скачивается и куда

Сборка не содержит тяжелых файлов. Программа спрашивает, прежде чем что-то скачать:

- модель распознавания имен GLiNER (`onnx-community/gliner_multi-v2.1`, fp16, около 580 МБ) — при первом распознавании; если Hugging Face закрыт в сети, можно указать заранее скачанный `model_fp16.onnx`;
- языковые файлы OCR (rus, ukr, eng, около 8 МБ) — при первом PDF-скане. Распознает встроенный в PyMuPDF Tesseract, ставить Tesseract отдельно не нужно.

Версии, размеры и контрольные суммы закреплены. Данные лежат в `%LOCALAPPDATA%\md-blinder`: `models\`, `tessdata\` и `history.sqlite`. Путь можно поменять переменной `MD_BLINDER_DATA_DIR`.

История хранит исходный текст и найденные значения без шифрования, как и браузерная версия. Экспорт истории в JSON совместим с браузерной версией в обе стороны.

## Сборка на Windows

Нужен Python 3.14: для onnxruntime пока нет сборок под 3.15. Права администратора не требуются.

```bat
py install 3.14
build.bat
```

`build.bat` создает `.venv`, ставит зависимости, прогоняет тесты и собирает папку `dist\MD Blinder` с `MD Blinder.exe` (около 330 МБ без модели). Папку можно скопировать куда угодно целиком. Для запуска из исходников без сборки есть `run.bat`.

`"MD Blinder.exe" --self-check` проверяет собранную программу без окна: зависимости, OCR и калибровку модели, если они скачаны. Отчет пишется в `%LOCALAPPDATA%\md-blinder\self-check.txt`.

Готовую сборку под Windows также выкладывает CI (workflow Desktop, артефакт `md-blinder-windows`). Файлы, скачанные из интернета, Windows помечает, и SmartScreen может предупредить при первом запуске; сборка на своем компьютере этого избегает.

## Разработка

```bash
cd desktop
py -3.14 -m venv .venv          # или python3.14 -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m pytest -q
.venv/Scripts/python -m md_blinder
```

Тесты с моделью и языками OCR запускаются, если файлы есть: модель ищется в каталоге данных (`MD_BLINDER_DATA_DIR`), языки OCR — в `MD_BLINDER_TESSDATA`.

Код повторяет модули браузерной версии один к одному, с теми же порогами и правилами; TS-тесты перенесены в `tests/`. Отличия:

- смещения сущностей считаются в кодовых точках Python, а не в UTF-16; при импорте и экспорте истории они пересчитываются;
- PDF разбирается PyMuPDF вместо pdf.js, координаты переводятся в систему pdf.js, чтобы пороги остались прежними;
- HTML из mammoth переводится в Markdown через markdownify с теми же правилами для таблиц, что у Turndown.

В первой версии нет ручек изменения границ сущности, синхронной подсветки при наведении и попапа объединения прямо в редакторе: объединение и смена типа доступны во вкладке «Найденные данные».
